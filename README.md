# Glina

Generated by `@wisent-ai/landing-cli@0.2.0` from a human-authored Wisent Components plan and an approved product brief. Do not hand-edit generated application files.

## Pipeline

1. `landing components` explains how to author the component decision file; every status and reason is decided by a human over `wisent-components/landing-components.json`.
2. `landing plan` authors copy only for components that decision file permits.
3. `landing generate` assembles the page from `wisent-components/src/landing-components.js`.
4. `npm run build:review` creates a non-public review build.
5. `npm run build` is the publication build; no step waits for a person's sign-off.
